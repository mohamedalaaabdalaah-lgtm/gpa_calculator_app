# 🎓 GPA Calculator App

A modern, fast, and dynamic desktop application built with Python to help students calculate their GPA, manage custom grading scales, and predict required grades for future academic goals.

---

## ✨ Features

- 📊 **GPA Calculation:** Calculate semester and cumulative GPA accurately.
- ⚙️ **Custom Scale Manager:** Easily create, save, and modify grade scales according to your university's system.
- 🎯 **Target Score Calculator:** Determine the grades needed in upcoming courses to hit your desired GPA goal.
- 💾 **Data Persistence:** Automatically save courses, scales, and preferences locally using JSON.
- 🎨 **Modern UI:** Clean, intuitive desktop interface built with CustomTkinter.

---

## 🚀 Download & Run (For Users)

No Python installation required! 

1. Go to the [Releases](https://github.com/mohamedalaaabdalaah-lgtm/gpa_calculator_app/releases) section.
2. Download the latest `GPA_Calculator_v1.0.zip` release.
3. Extract the ZIP file to any folder on your PC.
4. Run `main.exe` inside the extracted folder to start using the app.
